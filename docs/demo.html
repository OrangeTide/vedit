Line-number gutter

Toggle it from View › Line Numbers or, in vi keys, with :set number. The current line's number is drawn bright, the rest dim. It is the text-mode counterpart of the hex view's address column, and because each number rides with its line, the scroll fast path needs no extra work.

Word wrap

Toggle from View › Word Wrap or :set wrap. Long lines flow across rows at word boundaries instead of scrolling off the right edge. Display-only, so the file is unchanged.

One palette everywhere

The color scheme now drives the whole interface, not just the text body. The help screen used to be hardwired blue; here it is in both schemes. Header and footer take the bar colors; the body takes the text-area colors, so on the black scheme it falls through to the terminal default.

How

Scroll region

On a one-line scroll, set the VT100 region (DECSTBM) and emit one IND/RI, then repaint only the newly exposed line. Gated behind --scroll, off by default.

In-row span diff

Repaint only the columns between the first and last change on a row. After a scroll the moving scrollbar thumb costs one cell per row, not a whole row.

Erase-to-EOL

On the black scheme the text area is the terminal default background and runs to the last column, so a trailing blank run clears with one ESC [ K, safe with or without back-color-erase.

The black scheme drops the right border and vertical scrollbar to reach the last column; the file position stays on the status line. Both schemes, and the scroll fast path, are chosen per editor instance, so an embedding host can match each client.
